如何发布下一个版本

从 main 创建版本分支并推送，示例：

git checkout main
git pull origin main
git checkout -b v1.0.1
git push -u origin v1.0.1

发布工作流会根据版本分支创建对应 GitHub Release，并推送容器镜像。

GHCR 镜像能否匿名拉取取决于 Package 的可见性设置。若需要公开下载，请在 GitHub Packages 设置中确认镜像为 Public。
