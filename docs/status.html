健康检查

启动应用后访问以下地址检查服务状态：

http://localhost:8080/actuator/health
打开本地健康检查 ↗

该链接指向访问者自己的 localhost，不会自动检查 GitHub Pages 或远程服务器。

本项目当前可验证的内容

  • Spring Boot 应用可启动并监听默认端口。
  • /api/hello 返回欢迎 JSON。
  • /actuator/health 提供应用健康状态。
  • CI 工作流通过 Maven verify 执行构建与测试。
状态说明
此页面是静态说明页，不会伪造实时在线状态。需要远程实时监控时，应先将后端部署到可访问的服务器，再配置安全的状态查询接口。
