PROJECT DOCUMENTATION

项目架构

了解应用的技术组成、代码组织方式，以及从浏览器请求到 Spring Boot API 的基本流程。

系统组成

Frontend

Vue 3 + Element Plus

独立前端位于 frontend/，由 Vite 构建，通过 HTTP/JSON 调用 Spring Boot REST API。

Backend

Spring Boot

独立后端位于 backend/，使用 Java 21、Spring Boot 3.5.5 提供 REST API 和 Actuator 健康检查。

请求流程

1. 用户访问 Vue 前端Vite 开发服务器或前端静态托管返回 Vue 页面和资源。
2. 前端请求 APIVue 通过 HTTP/JSON 请求 backend/ 中的 Spring Boot 服务。
3. Controller 处理请求Spring Boot 的 HelloController 返回 JSON 响应。
4. 静态文档独立发布docs/ 继续由 GitHub Pages 托管，不参与 Vue 或后端构建。
