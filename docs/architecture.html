项目架构

了解应用的技术组成、代码组织方式，以及从浏览器请求到 Spring Boot API 的基本流程。

系统组成

Frontend

GitHub Pages

托管 docs/ 下的静态 HTML、CSS 页面，提供项目介绍与使用文档。

Backend

Spring Boot

Java 21 应用提供 REST API，并通过 Actuator 暴露健康检查。

请求流程

1. 用户访问静态站点GitHub Pages 返回 HTML、CSS 等静态资源。
2. 调用后端接口客户端向 Spring Boot 服务发送 HTTP 请求。
3. Controller 处理请求HelloController 返回 JSON 响应。
4. Actuator 提供健康信息运维端点可用于检查应用健康状态。
