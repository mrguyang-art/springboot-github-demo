CI/CD 自动化

通过 GitHub Actions 自动构建、测试、保存构建产物，并在版本分支上创建 Release 与发布容器镜像。

持续集成 CI

代码 Push 或 Pull Requestmain 分支变更触发 CI。
准备 Java 21 与 Maven 缓存Actions runner 配置构建环境。
执行 mvn -B verify编译项目并运行测试。
上传 JAR Artifactspringboot-jar 构建产物保留 7 天。

版本发布 CD

推送符合版本命名规则的分支（例如 v1.0.0）会触发发布工作流。

构建与测试再次执行 Maven verify。
创建 GitHub Release附加 JAR 文件并生成 Release Notes。
构建 Docker 镜像使用 Docker Buildx 构建镜像。
推送 GHCR发布版本号、次版本号和 latest 标签。

工作流文件

  • .github/workflows/ci.yml
  • .github/workflows/pages.yml
  • .github/workflows/release.yml
