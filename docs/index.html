GitHub Pages Demo

Spring Boot + GitHub Actions

这是一个演示项目：Spring Boot 提供 REST API，GitHub Actions 自动构建、测试，并将此静态站点发布到 GitHub Pages。

流水线步骤

  1. Push 代码到 main
  2. GitHub Actions 检出代码并配置 Java 21
  3. Maven 执行 mvn -B verify
  4. JUnit 自动运行接口测试
  5. Pages Workflow 上传 docs/ 并部署

后端 API

GET /api/hello 返回 JSON 欢迎消息。

GET /actuator/health 返回 Spring Boot 健康状态。
