快速开始

从本地运行 Spring Boot，到通过 Docker 启动应用，快速体验这个 Demo。

环境准备

JDK 21Maven 3.6+GitDocker（可选）

1. 克隆仓库

git clone https://github.com/mrguyang-art/springboot-github-demo.git
cd springboot-github-demo

2. 构建并测试

mvn -B verify

3. 启动应用

mvn spring-boot:run

4. 调用接口

curl http://localhost:8080/api/hello
curl http://localhost:8080/actuator/health

使用 Docker

先在项目根目录构建 JAR，再构建容器镜像：

mvn -B package
docker build -t springboot-github-demo .
docker run --rm -p 8080:8080 springboot-github-demo

常见问题

端口 8080 被占用？

停止占用该端口的进程，或通过 Spring Boot 配置更换端口。

构建失败？

检查 Java 版本是否为 21，并确认 Maven 可以访问依赖仓库。

健康检查 404？

确认应用已启动且 Actuator 依赖包含在当前构建中。
