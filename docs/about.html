关于项目

这是一个用于学习和演示 Spring Boot、GitHub Actions、Docker 与 GitHub Pages 的实践项目。

项目目标

通过一个规模适中的 Java Web 应用，把软件开发中常见的工程实践串联起来：代码管理、自动化测试、静态站点发布、版本管理和容器镜像发布。

学习重点

  • 使用 Spring Boot 编写 REST API。
  • 使用 JUnit 验证 Controller 行为。
  • 使用 GitHub Actions 自动执行 Maven 构建。
  • 使用 GitHub Pages 发布项目文档。
  • 使用 Docker 打包应用并发布到 GHCR。
