API 文档

当前 Demo 提供欢迎接口和 Actuator 健康检查接口。这里列出调用方式与响应示例。

GET /api/hello

返回一条欢迎消息，用于验证 Spring MVC Controller 是否正常工作。

成功响应示例

HTTP/1.1 200 OK
Content-Type: application/json

{
  "message": "Hello from Spring Boot!",
  "status": "success"
}

调用示例

curl http://localhost:8080/api/hello

GET /actuator/health

Spring Boot Actuator 提供的健康检查端点。默认健康状态通常返回 UP。

curl http://localhost:8080/actuator/health

示例响应：

{
  "status": "UP"
}

本地 API 地址

http://localhost:8080

尝试 Hello API ↗

只有在本机已启动 Spring Boot 应用时，此链接才可访问。

约定

  • HTTP 方法：GET
  • 数据格式：JSON
  • 默认端口：8080
  • API 以当前仓库实现为准
